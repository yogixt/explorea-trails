# Explorea Trails

A prototype travel-discovery app — browse destinations, view details, and plan trips. Part of the same lineage as the [Offbeats](https://github.com/yogixt/offbeat1.2) travel apps, built as a Lovable project exploring a broader (non-region-specific) destinations concept.

**Live:** [explorea-trails.vercel.app](https://explorea-trails.vercel.app)

![Explorea Trails landing page](docs/screenshot.png)

## Stack

- React · TypeScript · Vite · shadcn/ui · Tailwind CSS

## Development

```bash
npm install
npm run dev
```
